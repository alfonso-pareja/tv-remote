# tv-remote

Control remoto web (PWA) para TV Samsung Tizen (probado en UN58MU6120, 2017) que usa el puerto seguro 8002 con token.

## Uso
1. Abre la página de GitHub Pages en Safari del iPhone (misma red Wi‑Fi que la TV).
2. Si no conecta, toca **Autorizar certificado** y acepta el certificado de la TV.
3. Compartir → **Agregar a pantalla de inicio**.

La IP de la TV se cambia en ⚙︎. El token de la TV se guarda solo en el navegador del teléfono.
